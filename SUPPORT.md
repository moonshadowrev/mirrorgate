# Getting Support

## Before asking

1. Read the documentation in [`docs/`](docs/) and the commented `.env.example`.
2. Search existing [issues](https://github.com/moonshadowrev/mirrorgate/issues),
   open and closed.

## Where to go

| Need | Where |
|------|-------|
| Usage or deployment question | Open an issue using the "Question" template |
| Bug report | Open an issue using the "Bug report" template |
| Feature idea | Open an issue using the "Feature request" template |
| Security vulnerability | Private advisory: <https://github.com/moonshadowrev/mirrorgate/security/advisories/new> |
| Code of Conduct concern | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Tips for useful reports

- State your MirrorGate version, PHP version, SAPI, and hosting type.
- Describe each instance separately if you run several (one per domain, each
  with its own document root and `.env`).
- Redact secrets, tokens, cookies, and private hostnames. Never paste a full
  `.env`.

This is a community-maintained open source project provided without a support
guarantee or SLA.
